# Steward console

React, TypeScript, Vite and Tailwind v4. A placeholder page for now; Phase 1 adds the call log and approval cards.

```bash
pnpm install
pnpm dev
pnpm lint
pnpm build
```

pnpm is pinned in `package.json` (`packageManager`). Without a global pnpm, prefix the commands with `corepack`, for example `corepack pnpm build`.
